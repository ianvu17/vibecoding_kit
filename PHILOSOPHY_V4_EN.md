## 1. WHY DO YOU NEED TO CHANGE YOUR MINDSET?

### The old way: "AI follows orders"

You have an idea → You describe it in detail → AI designs it → AI code

**Problem:**
- You must know everything first (layout, colors, features...)
- AI only knows what you say, ignoring what you don't know to ask
- The results depend on your description ability

### New way: "AI & Human are partners"

You state the goal → AI proposes from experience → You provide context → Adjust together → AI code

**Benefit:**
- AI has "seen" millions of projects and knows which patterns are effective
- You just need to know your GOAL and CONTEXT
- The result is a combination: AI's expertise + your reality

## 4. NEW PROCESS: 6 STEPS

### Compare Flow

**v3.0 (5 steps - Human-driven):**
```
Intake → Blueprint → Contract → Build → Refine
  │          │           │         │        │
Human      Human       Human     AI       Both
 Request approval to sign refined code
```

**v4.0 (6 steps - Partnership-driven):**
```
Vision → Context → Blueprint → Contract → Build → Refine
   │        │          │           │         │        │
  AI      Human       AI+H       Both       AI      Both
Offer to provide refined confirm code consensus
```

## 5. GOLDEN RULE v4.0

### Principle 1: "AI recommends first, asks questions later"

```
❌ SAI (v3.0):
"Hello! To start, tell me:
 1. What do you sell?
 2. Brand color?
 3. Are there any references?"

✅ CORRECT (v4.0):
"Hello! For the landing page, I immediately propose this vision:
 [Detailed vision]
 
 This is a good template for 80% of cases.
 To customize for you, I need to know:
 1. Specific products?
 2. Do you have a brand yet?
 3. What's the difference?
```

### Principle 2: "Humans provide context, not solutions"

```
❌ SAI:
Host: "I want the hero section to have a blue-purple gradient,
         Montserrat font, button in the middle..."

✅ CORRECT:
Homeowner: "My customers are Gen Z, who like bold and trendy styles.
         The product is an English learning app."
         
→ Architect suggested: gradient, modern font, prominent CTA
```

### Principle 3: "One hour of Vision saves ten hours of Refine"

```
STEP 1+2 (Vision + Context): Invest 30-60 minutes
STEP 3+4 (Blueprint + Contract): Invest 15-30 minutes
STEP 5 (Build): AI takes 5-15 minutes
STEP 6 (Refine): 5-15 minutes (if Vision is good)
                                 2-5 hours (if Vision is poor)

→ Careful Vision = Little Refine
→ Clear vision = Refine is tired
```

### Principle 4: "Blueprint is a contract - does not change after signing"

```
AFTER STEP 3 (Blueprint approved):
✓ Can: Change text, small colors, content in section
✗ Cannot: Add section, change layout, change tech stack

Want big changes? → Go back to STEP 1, start Vision again
```

### Principle 5: "Builders are not allowed to be creative"

```
Builders (Claude Code) MUST:
✓ Code is 100% correct according to Blueprint
✓ Ask when encountering technical conflicts
✓ Progress reports

Builders MAY NOT:
✗ Decide to change the design yourself
✗ Add features that "look good"
✗ Use another tech stack

→ All creation happens in STEPS 1-3, not STEP 5
```

## 7. CONCLUSION

### Change summary

```
v3.0: Human knows everything → AI executes
v4.0: AI has vision → Human has context → Let's create products together
```

### Benefits for Homeowners (Human)

1. **No technical knowledge required**: Just need to know the goal and context
2. **Save time**: AI recommends 80% of the work
3. **Higher quality**: Based on proven patterns
4. **Less refinement**: Good vision from the beginning = less revision later

### Benefits to the process

1. **Faster**: AI doesn't wait, recommends now
2. **Consistency**: The Blueprint is the single source of truth
3. **Less conflict**: It's clear who decides what
4. **Easy to debug**: Know exactly which step the problem is at
